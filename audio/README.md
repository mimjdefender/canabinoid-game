# Audio Files Needed

Place the following audio files in this directory:

1. `bgm.mp3` - Background music (looping, relaxing electronic/ambient music)
2. `shoot.mp3` - Short "pew" or "whoosh" sound for shooting molecules
3. `hit.mp3` - Success sound for correct molecule-receptor matches
4. `miss.mp3` - Error sound for incorrect matches
5. `switch.mp3` - Quick switch sound for changing between THC and CBD

All audio files should be in MP3 format. You can find suitable royalty-free sound effects and music from websites like:
- freesound.org
- incompetech.com (for background music)
- pixabay.com/music/

Recommended characteristics:
- `bgm.mp3`: Relaxing, electronic/ambient music, 1-2 minutes long (will loop)
- `shoot.mp3`: Quick, soft "whoosh" or "pew" sound, 0.5-1 second
- `hit.mp3`: Pleasant success sound, 0.5-1 second
- `miss.mp3`: Soft error sound, 0.5-1 second
- `switch.mp3`: Quick switch/toggle sound, 0.2-0.5 seconds
